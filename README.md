# fidgital61-site

Официальный сайт Федерации фиджитал-спорта Ростовской области.

Текущая схема публикации: GitHub Pages из ветки `main`, каталог `/ (root)`.

Система заявок работает без Netlify: форма отправляет предварительные заявки напрямую в действующий Google Apps Script, который записывает их в рабочую Google-таблицу Федерации.

В одной предварительной заявке можно добавить нескольких спортсменов ритм-симулятора или несколько команд ДТС. Для ДТС каждая команда отправляется в реестр отдельной записью.

Для ускорения следующих заявок данные ранее введённых спортсменов, названия команд и последние составы сохраняются локально в браузере заявителя и доступны только при совпадении e-mail и телефона контактного лица. Очистка данных браузера удаляет этот локальный реестр.

Главная страница посвящена новостям. Разделы «Федерация», «Соревнования», «Документы», «Сборная» и «Контакты» вынесены на отдельные страницы.

Электронная заявка обозначена как предварительная и не заменяет официальный бумажный оригинал с медицинским допуском спортсменов и печатью медицинской организации.
