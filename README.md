# fidgital61-site

Официальный сайт Федерации фиджитал-спорта Ростовской области.

Автоматическая публикация: GitHub → Netlify.

Система заявок: несколько спортсменов/команд, повторный выбор спортсменов из реестра и серверное хранение через Netlify.

Реестр спортсменов привязан к e-mail и телефону контактного лица, чтобы повторный выбор не превращался в публичный поиск персональных данных.

Для ДТС также сохраняются названия ранее заявленных команд и их последний состав. При следующей заявке контактное лицо может начать вводить название команды и восстановить состав целиком.

Структура сайта: главная страница — новости; Федерация, соревнования, документы, сборная и контакты вынесены в отдельные разделы. Электронная заявка обозначена как предварительная и не заменяет бумажный оригинал с медицинским допуском.
